1. EXECUTIVE SUMMARY & CALIBRATED SCIENTIFIC ASSESSMENT
================================================================================

1.1 CORE ARCHITECTURAL THESIS
Standard autoregressive Softmax Attention computes output O_t by taking a weighted
sum over all historical values v_i:
  O_t = sum_{i=1}^t [ exp(q_t^T k_i / sqrt(D)) * v_i ] / sum_{i=1}^t exp(q_t^T k_i / sqrt(D))

Storing H_t = {(k_1, v_1), ..., (k_t, v_t)} creates an attention state footprint and
per-token decoding cost that scale monotonically with sequence length L.

PRIME Moment Attention converts this context-dependent historical storage into a
bounded recurrent moment state whose measured memory footprint and decoding cost
remain independent of sequence length L (scaling as O(D^2) with respect to head
dimension D), while retaining substantially more injected signal than the tested
first-order ELU+1 baseline.

1.2 CENTRAL EMPIRICAL PERFORMANCE FINDING
In evaluated implementations, PRIME maintained a bounded attention state and
approximately constant measured autoregressive decoding cost through a 1M-token
(1,048,576) context.

2. FORMAL MATHEMATICAL DERIVATION & TENSOR FORMULATION
================================================================================

2.1 TAYLOR EXPANSION AND THE O(D^2) DIAGONAL BOTTLENECK
Truncating the exponential expansion to second order:
  exp(x) approx 1 + x + 0.5 * x^2

Substituting x = (q_t^T k_i) / sqrt(D), the exact second-order quadratic term is:
  (q_t^T k_i)^2 = q_t^T (k_i k_i^T) q_t

A naive expansion yields the third-order outer product tensor:
  sum_{i=1}^t (k_i (x) k_i (x) v_i) in R^{D x D x D}
which pushes the state complexity to an unworkable O(D^3) (262,144 elements for D=64).

The Diagonal Second-Order Approximation resolves this by discarding off-diagonal
covariance terms:
  (q_t^T k_i)^2 approx sum_{d=1}^D (q_{t,d} k_{i,d})^2 = (q_t (o) q_t)^T (k_i (o) k_i)

This mathematical compromise restricts the maximum memory footprint of any moment
state strictly to O(D^2) (4,096 elements for D=64, a 64x parameter reduction).

2.2 RECURRENT STATE EQUATIONS
Using per-head decay filter lambda_h in (0, 1):

Numerator States (Information Payload):
  - Zeroth-Order (D x 1): S^{(0)}_t = lambda_h * S^{(0)}_{t-1} + v_t
  - First-Order  (D x D): S^{(1)}_t = lambda_h * S^{(1)}_{t-1} + (k_t v_t^T)
  - Second-Order (D x D): S^{(2)}_t = lambda_h * S^{(2)}_{t-1} + ((k_t (o) k_t) v_t^T)

Denominator States (Partition Normalizer):
  - Zeroth-Order (Scalar): Z^{(0)}_t = lambda_h * Z^{(0)}_{t-1} + 1
  - First-Order  (D x 1):  Z^{(1)}_t = lambda_h * Z^{(1)}_{t-1} + k_t
  - Second-Order (D x 1):  Z^{(2)}_t = lambda_h * Z^{(2)}_{t-1} + (k_t (o) k_t)

Output Readout (strictly O(D^2) compute, independent of sequence length L):
  O_t = [ S^{(0)}_t + (1/sqrt(D)) S^{(1)}_t q_t + (1/(2D)) S^{(2)}_t (q_t (o) q_t) ] /
        [ Z^{(0)}_t + (1/sqrt(D)) Z^{(1)}_t q_t + (1/(2D)) Z^{(2)}_t (q_t (o) q_t) ]

2.3 EMPIRICAL VULNERABILITIES & THE MANDATORY QK-NORM REQUIREMENT
Polynomial approximations of exponential functions exhibit specific mathematical properties:
  1. THE PARABOLIC REBOUND (x < -1):
     Softmax strictly squashes negative logits toward zero (lim_{x -> -inf} exp(x) = 0).
     The polynomial P(x) = 1 + x + 0.5*x^2 = 0.5*(x+1)^2 + 0.5 >= 0.5 has its global
     minimum at x = -1. For x < -1, the polynomial rebounds upward:
     at x = -10, exp(-10) = 4.5e-5, whereas P(-10) = +41.0.
     Without constraint, strongly rejected tokens receive massive positive attention!
  2. DIVERGENCE AT |s| >> 1:
     In un-normalized pretrained Transformers, raw dot products regularly reach |s| = 20-100.
     Taylor expansions around 0 diverge violently at these scales.
  3. MANDATORY QK-NORMALIZATION:
     To keep |s| <= 1 where the Taylor expansion is valid, strict per-head Query-Key
     normalization (RMSNorm or LayerNorm) is an absolute necessity, not an optional
     embellishment. With QK-Norm, attention logits remain within the stable radius.
