1. EXECUTIVE SUMMARY & CALIBRATED SCIENTIFIC ASSESSMENT
================================================================================

1.1 CORE ARCHITECTURAL THESIS
Standard autoregressive Softmax Attention requires storing every historical key-value
pair H_t = {(k_1, v_1), ..., (k_t, v_t)}, creating an attention state footprint and
per-token decoding cost that scale monotonically with sequence length L.

PRIME Moment Attention converts the context-dependent historical storage and repeated
scanning of conventional autoregressive attention into a bounded recurrent moment
state whose measured memory footprint and decoding cost remain independent of sequence
length L (scaling as O(D^2) with respect to head dimension D), while retaining
substantially more injected signal than the tested first-order ELU+1 baseline.

1.2 CENTRAL EMPIRICAL PERFORMANCE FINDING
PRIME maintained a bounded attention state and approximately constant measured
autoregressive decoding cost through a 1M-token (1,048,576) context.

2. FORMAL MATHEMATICAL DERIVATION & TENSOR FORMULATION
================================================================================

2.1 GROUND-TRUTH CAUSAL SOFTMAX ATTENTION
  y(q_t) = sum_{j=1}^t softmax( (q_t . k_j) / sqrt(d) ) * v_j
         = sum_{j=1}^t [ exp(s_{tj}) / sum_{m=1}^t exp(s_{tm}) ] * v_j
  where s_{tj} = (q_t . k_j) / sqrt(d).

2.2 2ND-ORDER TAYLOR POLYNOMIAL EXPANSION
Expanding exp(s) around s = 0:
  exp(s) = 1 + s + (1/2) * s^2 + O(s^3)

The second-order scalar term expands as:
  s^2 = ( (q^T k) / sqrt(d) )^2 = (1 / d) * q^T (k k^T) q

Therefore, the exact second-order Taylor expansion yields:
  Numerator:   N(q) = S_0 + (1 / sqrt(d)) * q^T S_1 + (1 / (2d)) * q^T S_2 q
  Denominator: D(q) = K_0 + (1 / sqrt(d)) * q^T K_1 + (1 / (2d)) * q^T K_2 q

Where the full outer-product moment tensors are:
  - S_0 = sum_{j=1}^t v_j                     [D]         (0th value moment)
  - S_1 = sum_{j=1}^t k_j v_j^T               [D, D]      (1st covariance tensor)
  - S_2 = sum_{j=1}^t (k_j (x) k_j) (x) v_j   [D, D, D]   (2nd-order rank-3 tensor)
  - K_0 = sum_{j=1}^t 1                       [1]         (0th key count)
  - K_1 = sum_{j=1}^t k_j                     [D]         (1st key mean)
  - K_2 = sum_{j=1}^t k_j k_j^T               [D, D]      (2nd key covariance)

2.3 THE DIAGONAL SECOND-ORDER MOMENT APPROXIMATION (PRIME IMPLEMENTATION)
Notice that maintaining the full rank-3 tensor S_2 requires O(D^3) storage per head.
For head dimension D = 64, D^3 = 262,144 elements (1.05 MB per head).

To preserve O(D^2) state compactness matching S_1, PRIME Moment Attention employs a
diagonal second-order approximation:
  k_j k_j^T approx diag(k_j^2)

Under this diagonal formulation:
  - S_2_diag = sum_{j=1}^t (k_j^2) v_j^T      [D, D]      (O(D^2) state size!)
  - K_2_diag = sum_{j=1}^t k_j^2              [D]         (O(D) state size)

And the readout contracts as:
  y(q) = ( S_0 + (1/sqrt(d)) q^T S_1 + (1/(2d)) (q^2)^T S_2_diag ) /
         ( K_0 + (1/sqrt(d)) q^T K_1 + (1/(2d)) (q^2)^T K_2_diag )

For D = 64, this reduces the 2nd-order parameter count from 262,144 down to 4,096
elements per head (a 64x memory saving), while capturing quadratic magnitude curvature.

2.5 THE POLYNOMIAL CONVERGENCE REGIME & NORMALIZATION REQUIREMENT
A crucial mathematical finding:
For s in [-1.0, 1.0], the polynomial 1 + s + 0.5 s^2 closely approximates exp(s).
However, for s << -1.0, exp(s) -> 0, whereas the quadratic term 0.5 s^2 dominates and
causes poly(s) -> +infinity!
  e.g.: at s = -10.0: exp(-10.0) = 0.000045, but 1 - 10 + 0.5*(-10)^2 = +41.0!

Consequently, un-normalized zero-shot substitution on models whose raw dot products
reach |s| = 50-100 causes severe distribution distortion. To operate correctly,
PRIME Moment Attention requires per-head LayerNorm/RMSNorm on Queries and Keys (QK-Norm)
or fine-tuning/distillation so that projection weights align with the polynomial kernel.
